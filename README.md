# Умка — учусь у тебя!

Универсальный педагогический лайфхак для школьного конкурса. Четыре режима: «Объясни мне», «Найди мою ошибку», «Приведи пример», «Экзамен для Умки». Без ИИ, API и платных сервисов.

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Размещение в интернете

1. Создайте репозиторий `umka-virtual-student` на GitHub.
2. Загрузите `app.py`, `requirements.txt` и `README.md`.
3. В Streamlit Community Cloud выберите репозиторий и `app.py`, затем Deploy.

## Использование

1. Откройте боковую панель учителя и задайте тему и реплики Умки.
2. Сохраните сценарий в JSON для следующего урока.
3. На интерактивной доске выберите этап и попросите учеников отвечать устно.
4. Учитель решает, когда показать следующую реплику и отметить этап пройденным.
5. После четырёх этапов появляется поздравление.

## Важно

Умка не распознаёт и не оценивает речь и ответы. Реплики заранее задаёт учитель. Прогресс — условный игровой индикатор. Изменения сценария в браузере не сохраняются после сброса сессии: экспортируйте JSON. В версии для Streamlit Cloud приложению нужен интернет, но ИИ и платные API не используются.


В новой версии персонаж — нарисованный школьник. Файл `umka_schoolboy.svg` обязателен рядом с `app.py`. Глаза моргают, рот двигается, рука машет; картинка встроена в интерфейс.


Исправление анимации: персонаж теперь отображается как встроенный SVG в HTML-компоненте Streamlit. Моргание, жест рукой, движение рта и покачивание работают независимо от остальных кнопок и прогресса. Все 4 этапа и редактор сценариев сохранены.


Исправлено: для любопытства, размышления и радости используются ТРИ РАЗНЫХ SVG-файла с разной мимикой и движениями. При смене этапа картинка действительно меняется. Загрузите ВСЕ SVG-файлы в репозиторий рядом с app.py.


Озвучка: кнопка «Озвучить реплику» читает текст через Web Speech API браузера. Рот двигается во время воспроизведения. Нужен браузер с поддержкой синтеза речи и установленный русский голос. Автозапуска нет. Качество и доступность голоса зависят от браузера, иногда его сервисов.
